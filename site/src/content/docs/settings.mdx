Settings are saved to [`Settings.json`](/docs/files/) and can also be edited there directly.

## General

| Setting | Default | What it does |
| --- | --- | --- |
| **Master password** | Empty | Set a password and press **Apply** to encrypt `Accounts.json`; clear it to store plain text. See [Encryption](/docs/encryption/). |
| **Launch minimized** | Off | Starts GW Launcher hidden in the [system tray](/docs/tray/). |

## Updates

| Setting | Default | What it does |
| --- | --- | --- |
| **Check for updates** | On | Checks for a new GW Launcher release on startup. |
| **Auto update** | Off | Downloads and applies launcher updates automatically. |

## Advanced

| Setting | Default | What it does |
| --- | --- | --- |
| **Game window timeout (seconds)** | 20 | How long to wait for the game window to appear (`MainWindowHandle`), then for input readiness (`WaitForInputIdle`). Each step gets this timeout. Applies even without mods; raise it if clients start slowly or you launch many clients. |
| **Mod launch timeout (seconds)** | 10 | How long to wait for each mod DLL to load. Raise it if mod loading times out. This does not affect the game window timeout. |

Both timeouts use whole seconds, from 1 to 4294967. For example, enter **30** to wait 30 seconds. Decimal values are rounded to the nearest whole second when saved.
`Settings.json` stores these values in milliseconds as `TimeoutOnGameWindow` and `TimeoutOnModlaunch`. Existing values are displayed rounded to whole seconds (minimum 1 second); older settings files default to a 20-second game window timeout.

<div class="note">

These settings configure the **launcher**. Per-account options (path, extra arguments, run
elevated, which mods to load) live in each account's window — see
[Managing Accounts](/docs/accounts/).

</div>
